# Installation

## Steps

### 1. Install the plugin

#### From a file

1. Clone this repository.
2. Open Blockbench.
3. Go to `File -> Plugins... -> Load Plugin from File`. Navigate to `plugins/edge_noise_brush` in the cloned repository and select `edge_noise_brush.js`.
4. To confirm the plugin installed correctly, go to `File -> Plugins...`. Under the "Installed" section you should see `Edge Noise Brush`.

### 2. Open it

Switch to the Paint tab and click the small arrow on the Brush tool in the toolbox. Pick `Edge Noise Brush`, `Noise Brush`, `Highlight Brush`, `Shadow Brush` or `Block Grid Brush` from the dropdown. The Brush tool's icon changes to that mode's icon while it is active, and the Edge Noise Brush panel opens on the right.

The first time, Blockbench asks for permission for the plugin to use its preset folder. Choose `Always allow for this plugin`.

## Requirements

- Blockbench 5.0 or newer.
- The preset folder needs the desktop app. In the web version presets are kept in the browser instead.
