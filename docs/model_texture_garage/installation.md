# Installation

## Steps

### 1. Install the plugin

#### From a file

1. Clone this repository.
2. Open Blockbench.
3. Go to `File -> Plugins... -> Load Plugin from File`. Navigate to `plugins/model_texture_garage` in the cloned repository and select `model_texture_garage.js`.
4. To confirm the plugin installed correctly, go to `File -> Plugins...`. Under the "Installed" section you should see `Model & Texture Garage`.

### 2. Open it

#### Brushes


Switch to the Paint tab and click the small arrow on the Brush tool in the toolbox. Pick `Edge Noise Brush`, `Noise Brush`, `Highlight Brush`, `Shadow Brush` or `Block Grid Brush` from the dropdown. The Brush tool's icon changes to that mode's icon while it is active, and the Texture Garage panel opens on the right.

#### Block Grid Cube tool

In the Edit tab, pick the `Block Grid Cube` tool from the toolbox. Its mode and cube size show in the tool bar at the top.

#### Presets

The first time, Blockbench asks for permission for the plugin to use its preset folder. Choose `Always allow for this plugin`.

## Requirements

- Blockbench 5.0 or newer.
- The preset folder needs the desktop app. In the web version presets are kept in the browser instead.

## Coming from the Edge Noise Brush

This plugin replaces the separate Edge Noise Brush and Block Grid Modeler plugins. Uninstall those first. Your settings, presets and preset folder carry over as they are.
