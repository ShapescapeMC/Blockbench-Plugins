# Installation

## Steps

### 1. Install the plugin

#### From a file

1. Clone this repository.
2. Open Blockbench.
3. Go to `File -> Plugins... -> Load Plugin from File`. Navigate to `plugins/block_grid_modeler` in the cloned repository and select `block_grid_modeler.js`.
4. To confirm the plugin installed correctly, go to `File -> Plugins...`. Under the "Installed" section you should see `Block Grid Modeler`.

### 2. Open it

In the Edit tab, pick the `Block Grid Cube` tool from the toolbox. Its options, the mode and the cube size, show in the tool bar at the top.

## Requirements

- Blockbench 5.0 or newer.
