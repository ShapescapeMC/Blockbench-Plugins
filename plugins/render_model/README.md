# Render Model

Renders the model you have open into finished images and GIFs, from preset camera angles, at one or more resolutions, in a single pass.

- Still PNGs from the four sides, the top and bottom, the isometric corners, your current viewport, or any number of views spaced around the model.
- A looping turntable GIF, with animations playing underneath it if you want them.
- A looping GIF per animation, with other animations layered on top, so an idle or a blink can play over a walk cycle.

Everything is set in one dialog under `View -> Render Model...`, and every run writes into its own numbered folder. Requires Blockbench 5 on desktop.

[Learn More](https://blockbench-plugins.readthedocs.io/en/latest/render_model/about.html)
